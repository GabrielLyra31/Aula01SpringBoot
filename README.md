# API de Receitas

API REST de receitas culinárias desenvolvida com Spring Boot.

## Tema

Esta API apresenta receitas culinárias, incluindo uma receita em destaque e uma lista de receitas disponíveis.

## Como executar

O projeto utiliza Spring Boot e está configurado para utilizar a porta **8081**.

Para executar pelo Maven Wrapper:

### Windows

``bash
.\mvnw.cmd spring-boot:run

### Linux/macOS
./mvnw spring-boot:run
